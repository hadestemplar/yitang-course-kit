# 数据包（course-data-package）

## 三层里的位置

```
① 抓课包      →  课程信息底稿（原样、可追溯，给下游用）
② 数据包      →  操作手册（能照着干，给 Agent 用）      ← 本技能
③ 清单体笔记  →  课程快照（给人看，可读）
```

**输入必须是底稿，不是原课。**底稿没有的东西，数据包里一律不出现——不许拿常识补。

## 底稿 vs 数据包：一条判据分清

| | 底稿 | 数据包 |
|---|---|---|
| 回答的问题 | 课程**说了什么** | 遇到情况**怎么做** |
| 形态 | 原文 + 出处（A/B/C 档） | 条件 → 动作 → 合格判据 |
| 判断标准 | 能不能追溯到原话 | 照它做，做出来的东西合不合格 |
| 删掉会怎样 | 丢了原文 | 丢了操作能力 |

**写数据包时只问一句**：这一条是"知识"还是"操作"？是知识就压成一句，是操作就写成可执行指令。

## 数据包模板（八节，缺节即为不合格）

```markdown
# <课题> · 数据包 v<版本>（操作手册型）

> 一句话用途｜来源底稿路径 + 版本｜适用对象（Agent）

## 0 怎么用（三步，不超过 10 行）
## 1 触发判定：什么输入该用这个包 / 什么不该用
## 2 开工前四问（输入审查：目标档位 / 场景 / 素材完整度 / 禁区）
## 3 执行流程（S1…Sn，按顺序，每步写"输入→动作→产物"）
## 4 规则库（按档位/场景分组，每条三段式：动作｜合格判据｜反例）
## 5 自检清单（机械可核对，能一眼判对错）
## 6 模板（可直接套的骨架 + 一处填写示例）
## 7 错误清单（"看到 X → 改成 Y"，一条一行）
## 8 溯源（每条规则指向底稿行号或章节）
```

## 契约层六件（2026-10-30 立；不做这六件，将来做 Skill/插件必然返工）

八节模板管「内容对不对」，这六件管「下游能不能直接用」：

1. `§0.5 输入分级`：L0 叙述型 / L1 有目标无数据 / L2 齐全——各自能产出到哪一件、必须标什么、缺数据时停在哪。
2. `§2.5 分支表 + 停机问句`：触发条件 → 从哪一步进 → 产出差异；问句最多 3 句。
3. `§3.5 输出契约`：D1…Dn 每件交付物的字段级定义 + 缺口清单 G。
4. `§4.0 优先级`：必做最小闭环 / 可省 / 仅参考，标出规则 ID。
5. `§4.5 术语映射`：用户常用说法 → 本包术语 → 处理方式。
6. `§6.5 黄金样例`：一段示例输入 → 一份示例输出，**标明是示例不是课程原话**。

硬约束：契约层内容由工程师约定产生，**不是课程原文**；写法上必须与课程原文分开（课程原文一律带底稿行号），并在溯源节加一行「契约层无课程来源」。
## 规则写法（本技能的核心约束）

一条规则必须三段齐全，缺一段就是知识不是操作：

```
- 动作：做什么（动词开头，可执行）
  判据：怎么算做对了（可观测、可机械核对）
  反例：做错了长什么样（引自底稿或底稿反例，不自己编）
```

禁止：
- **只抄原话不动**——数据包不是摘抄本，原话只用来支撑判据。
- **不可观测的判据**（"要清晰""要简洁"）——改成可数的（"每行 ≤ 最大宽度不换行""层数 ≤ 3"）。
- **编造阈值**——底稿里没有的数字不许出现；确需判断的地方给结论 + 理由，不给打分表。
- **落地建议**——"你可以拿它做 X"不属于数据包。
- **把本课不展开的点代填方法**——底稿写「本课只给名、方法在《X》」时，规则库可保留该条但必须标 `〔他课·课名〕`，方法细节**不许自己补**（反例：某课 18 招里第 13–15 招本课明确「不展开了」，只能引用本课那句话，不能替它写访谈/调研/实验怎么做）。
- **段位/地图/评分刻度进规则库**——这些是过程性构件（爬山路、L1–L6、及格线），只在底稿留证，不进 §4；它们打进规则库就等于编造阈值。

## 执行步骤

1. **读底稿，标出可操作项**：把"怎么做/要不要/合格吗"类的句子挑出来，标行号；纯背景（讲师经历、课程历史）跳过。
2. **按档位/场景分组**：同一场景的规则放一起，组内按执行顺序排（不是按原文顺序）。
3. **逐条改写成三段式**：动作 / 判据 / 反例。改写不了的（只有描述没有动作）降级到 §1 或删。
4. **写流程**：把规则串成一条能从头跑到尾的路径，每步写明输入、动作、产物。
5. **写自检清单**：只收可机械核对的条目；需要"判断"的（值不值得、够不够）不进清单，写成一句话结论。
6. **写错误清单**：把底稿的"失效条件/偏差"改写成"看到 X → 改成 Y"。
7. **回溯校验**：每条规则都能指回底稿行号；指不回去的删掉。

## 验收

- [ ] 六件契约层齐（§0.5/§2.5/§3.5/§4.0/§4.5/§6.5），且与课程原文分开写

1. 八节齐全，§4 每条都是三段式。
2. §5 每一条都能机械核对（能写成一个命令或一次肉眼比对）。
3. 数据包里出现的每个数字/术语都能在底稿里找到。
4. 一个没有读过原课的人（或 Agent）拿着它，能从零做出一份合格产物。
5. 全文没有落地建议、没有打分表。
