# yitang-course-kit · 把一堂课程抓成底稿，再把底稿编译成 Agent 能直接跑的数据包

两个 Skill，一条流水线：

```
一门一堂课程  ──抓课包──▶  课程信息底稿（公共层素材）  ──数据包──▶  可执行数据包（给 Agent 用）
```

底稿回答「这门课说了什么」，数据包回答「照着这门课，下一步具体怎么做」。

---

## 一、它解决什么问题

- **课程是视频 + 一张几万像素的长图大纲**，Agent 读不到；官方接口 `course.sections` 常常直接返回空数组，唯一的大纲印在一张 1400×16251 的长图上。
- **直接在对话框里问「帮我总结这门课」会得到编造**：Partner 被问课程时会走联网搜索而不是课程知识库，课名、课号、场次全是它拼出来的。抓课包必须指定课程版 AI，并逐条证伪。
- **底稿很容易做成「元信息 + 几句摘要」**，看起来齐整，下游一个字也用不了。这个库把底稿的形态写死：内容本体原样保留、占全文 ≥ 80%，元信息只留 `§0`。
- **数据包常常只是文章的另一种排版**，下游 Agent 拿到后不知道从哪一步开始、缺什么该停、产出该长什么样。这个库给数据包加了一层「契约」：输入分级、分支表、输出契约 D1–D6、最小闭环优先级、黄金样例。

## 二、它是什么

| Skill | 作用 | 入口文件 |
|---|---|---|
| `course-pack-capture` | 把一门课抓成「课程信息底稿」（公共层素材），供下游两条分支复用 | `skills/course-pack-capture/SKILL.md` |
| `course-data-package` | 把底稿编译成「操作手册型数据包」——给 Agent 照着干的可执行规格 | `skills/course-data-package/SKILL.md` |

配套阅读：

- `references/契约层六件.md` —— 数据包能被下游直接吃掉的六个硬要求（两个 Skill 共用）
- `examples/` —— 脱敏示例，**全部是自造素材，不是任何一门课的原话**

## 三、前置条件

- 已安装并登录 YAI CLI（`whyai --version` ≥ 0.7.0），账号为**思考版及以上**且在有效期内（`whyai billing access` 返回 `eligible: true`）
- 有 Node.js ≥ 20 可执行（`whyai` 的启动器会写死安装时的 node 路径）
- 配额：`whyai chat` 按次计费，**一次调用约 2 个配额点**；抓一门课通常 4–6 轮
- 课程库接口（`whyai yitang …`）**不扣配额**

## 四、安装

把两个目录复制到你的技能目录：

```bash
cp -r skills/course-pack-capture  ~/.dsh/skills/
cp -r skills/course-data-package  ~/.dsh/skills/
```

（Claude Code 等其它宿主：放到该宿主的 skills 目录，SKILL.md 的 frontmatter 是通用的。）

## 五、怎么用

| 你说 | 发生什么 |
|---|---|
| 「抓一下这门课：全员必修·重新理解「战略会」」 | 走 `course-pack-capture`：开工自检 → 免费接口定位课程 → 取官方大纲长图 → 分轮问课程版 AI → 换 Partner 对账 → 数量对账 → 落底稿 |
| 「用这份底稿做个数据包」 | 走 `course-data-package`：判底稿完整性 → 抽规则（每条三段式：动作｜判据｜反例）→ 写契约层六件 → 自检 → 落包 |

产物默认落本地工作区，**不进本库**。

## 六、验收线（能被机械核对的那几条）

底稿：

- 一级节为 `00 元信息 / 01 内容本体 / 02 图示原件 / 03 术语与邻课边界 / 04 缺口清单 / 05 原文附件`
- 内容本体占全文 ≥ 80%
- **数量对账**：详情页/大纲承诺 N 个阶段/步/招/层，实到条目数并排写出，两个数字必须相等；缺项进缺口清单，不许拿后一阶段的成果顶替
- **收尾段必录**：底稿能回答「这门课是怎么结束的」（结课结论、作业怎么交、Candy 是什么）；删除测试不作用于收尾段

数据包：

- 九节齐全（`0 怎么用 / 1 触发判定 / 2 开工前四问 / 3 执行流程 / 4 规则库 / 5 自检清单 / 6 模板 / 7 错误清单 / 8 溯源`）
- 规则库每条三段式；编号可回溯到课程原文或明确标「本包工程约定」
- **契约层六件**齐全（见 `references/契约层六件.md`）；缺一件，下游就得重构

## 七、已知边界（踩过的，写在前面）

- **Partner 不服从结构性微指令**：要求它「只答这两块」，它常常改写成「缺口闭合 / 封版声明」。对策是分轮问、一轮只问 1–2 个缺口，并把返回当成素材而不是结论。
- **课程版 AI 之外的 Partner 会联网编课名**，一切课名课号以课程版 AI（`a0000000-0000-0000-0000-000000000001`）为准，其余来源只能标「待核实」。
- **`course.sections` 返回空 ≠ 这门课没有结构**，结构在 `course.detail` 的长图上；超过 3 屏要切块逐块读。
- **同一门课的不同课之间高度同文**（例如「五步法」认知篇与进阶篇），逐字原话必须先判归属，否则会把别的课的内容写进本科目。
- 抓取结果里出现中文时，PowerShell 5.1 捕获外部命令输出前必须设 `[Console]::OutputEncoding = UTF8`，否则 GBK 解码会吃掉引号导致 JSON 解析失败。

## 八、本库刻意不含什么

不含任何**课程底稿、数据包、清单体笔记**——那是使用者自己的抓取产物。`examples/` 里的示例全部为自造素材。

技能正文里保留了少量「本地底稿 `:` 行号」形式的引用，它们指向使用者在本地生成的底稿，公开库里不存在对应文件，按语义理解即可。
